# 怎么玩：点亮知识点

这是一张「知识地图」的规则说明。现在还没有完整游戏客户端，用 JSON 地图 + 校验脚本就能把规则跑通。以后 UI 按这里的状态来画。

## 一句话

每个知识点是地图上的一盏灯。完成绑在这盏灯上的任务（Quest），灯就亮。灯亮了，后面连着的灯才可能打开。打过章节关主，整张地图通关。

## 节点五种外观（UI 状态）

对应 `player-progress.schema.json` 里的 `state`：

| 状态 | 玩家看到 | 能不能做任务 |
| --- | --- | --- |
| `locked` | 灰灯、实心锁 | 不能。最多预览标题 |
| `available` | 亮边框、可点 | 可以开始 |
| `learning` | 半亮、进度条 | 正在做任务 |
| `lit` | 点亮 | 已掌握，可复习 |
| `needs_review` | 闪烁 / 小月亮 | 曾经点亮，建议再练 |

**起点**（`map.meta.json` 的 `start_node_ids`）进图时直接是 `available`，不必从 `locked` 走。

样例地图起点：`pm-g1-n001`「数一数（10以内）」。小学二十四张、初中十二张、高中十一张样例地图都按本文规则，各自独立通关。

## 硬前置 vs 软锁

边的 `type: prerequisite` 决定推荐顺序。节点上的 `unlock_rule.type` 决定锁有多硬：

### 硬前置 `hard_all_prereqs`（默认）

- 列出的每个前置节点都必须是 `lit`（或仍算掌握的 `needs_review`）
- 少一盏灯，本节点保持 `locked`
- 用来保证计算技能真的按「会分与合 → 再会加减」往前走

### 软锁 `soft_recommended`

- 地图上画**虚线锁**，并提示「建议先点亮某某」
- 玩家仍可点进去做任务（例如一年级的「第几：基数与序数」是认识 1～5 之后的支线，不挡住后面的加减）
- 老师/家长若打开 `allow_teacher_override`，硬前置也可以破例，但通关统计会记一笔「跳过」

**和关主的关系：** 软锁支线仍算「点亮全部节点」通关条件的一部分，只是不挡主路。想先打主线也可以，最后回来点亮支线。

## 点亮一盏灯（掌握）

节点带 `mastery_criteria`。典型要求：

1. 至少完成 `min_quests_cleared` 个绑定任务
2. 若写了 `require_quest_types`，这些类型都要有（例如计算节点常要求 `practice`）
3. 若有小测，正确率不低于 `min_quiz_accuracy`（样例里多为 0.8）

达到标准 → 状态变为 `lit`，并获得一次「点亮奖励」经验。

## 经验 XP（建议数值，Phase 1 约定）

| 事件 | XP |
| --- | --- |
| 完成 `explain` | 10 |
| 完成 `practice` | 15–25 |
| 完成 `mini_quiz` | 25–30 |
| 击败 `boss` | 80–100 |
| 首次点亮该节点 | +10 |
| 整张地图通关 | +100 |

`player-progress` 里 `xp_total` 是累计；每个节点还有自己的 `xp_earned`。以后做等级、称号，都从这两处读，不要另做一套账。

## 任务四种

| 类型 | 干什么 | 适合 |
| --- | --- | --- |
| `explain` | 用自己的话、手指、学具讲清楚 | 概念、组成、策略 |
| `practice` | 短练习 | 口算、读写、比较 |
| `mini_quiz` | 混合检查 | 章节中段 |
| `boss` | 关主，多段条件一次性过 | 章节末 / 地图末 |

每个节点至少 1 个任务。样例地图另外有 **3 个关主**：

1. `pm-g1-boss-10` 十以内加减大闯关（绑在「加减混合」）
2. `pm-g1-boss-20` 二十以内进退位（绑在「20以内退位减法」）
3. `pm-g1-boss-map` 一年级数与运算通关试炼（绑在终章综合节点）

关主失败不掉级，节点保持 `learning`，可以再挑战。

## 通关（Win）

读 `map.meta.json` 的 `win_condition`。样例是：

- 点亮**全部**节点（含软锁支线）
- 且三名关主任务都在 `cleared_quest_ids` 里

满足后，把地图 id（`pm-g1-numbers`）写入 `cleared_map_ids`。

## 复习 `needs_review`

`mastery_criteria.review_after_days` 到了，且这段时间没有再做该节点任务：

- `lit` → `needs_review`
- 地图上灯还在，但变暗一档
- 完成一次练习或小测，重新变回 `lit`
- **不**把后续节点重新锁死（避免「复习把主线打回去」的挫败感）

## 边在 UI 上怎么画

| 边类型 | 画法 |
| --- | --- |
| `prerequisite` | 实线箭头，从上到下（或从左到右） |
| `related` | 淡色虚线，无箭头或双箭头 |
| `easily_confused` | 警告色虚线，可点开「哪里容易混」 |
| `application` | 从技能指向应用题节点的点线 |

只有 `prerequisite` 参与解锁和环检测。

## 建议的主线节奏（一年级这张图）

1. 数一数 → 认识 1～5 → 分与合 → 5 以内加减  
2. 认识 6～10 → 10 的分与合 → 10 以内加减与混合 → **关主 1**  
3. 11～20 与十几组成 → 不进位/不退位 → 凑十法 → 进位加  
4. 破十 / 想加算减 → 退位减 → **关主 2**  
5. 加减关系、一共与还剩  
6. 整十数到 100、读写组成比较、整十与两位数加减  
7. 比多比少、口算熟练 → **关主 3 通关**

序数「第几」是旁边一盏灯，随时可点。

## 和「游戏客户端」的边界

Phase 1 **不**实现战斗动画。任何客户端只要：

1. 读四个 JSON + 玩家存档  
2. 按本文改状态  
3. 用 `python3 scripts/validate_map.py` 保证地图合法  

就算实现了这套玩法。
