## 年级之间怎么衔接（先只写在这里）

一年级终章的「100 以内数与整十加减」和二年级起点「100 以内组成复习」在教学上是接着的。  
**现在两张地图各自独立通关**：校验器只认本目录里的节点 id，存档也按 `current_map_id` 分开算。

以后若做多图进度，可以：

- 用 `cleared_map_ids` 记录「一年级图已通关」，再推荐打开二年级图
- 或加 `related` 边说明概念衔接

**不要**在二年级的 `prerequisites` 里写 `pm-g1-*`——那会让单图校验失败，也还没有跨地图解锁引擎。

---

补新地图时：复制 `grade-1-numbers/` 或 `grade-2-numbers/` 的四个 JSON，改 `map.meta.json` 的 `id` / `title` / `start_node_ids`，跑：

```bash
python3 scripts/validate_map.py maps/primary-math/<新目录>
```

已有地图：

```bash
python3 scripts/validate_map.py maps/primary-math/grade-1-numbers
python3 scripts/validate_map.py maps/primary-math/grade-2-numbers
python3 scripts/validate_map.py --all
```
